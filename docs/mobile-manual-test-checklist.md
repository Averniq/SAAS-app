# Mobile manual checklist

Test 320, 360, 375, 390, 430 and 768px: login/signup/recovery/verification; setup/onboarding QR; kitchen status buttons; menu/table forms; reports; token and legacy public ordering pages. Confirm no horizontal scroll, touch targets remain visible above safe areas, and merchant navigation is absent from public ordering.

Test offline mode: disconnect, verify banner and blocked/error writes, reconnect and verify refresh. Install the PWA and verify offline fallback, update behavior, and no authenticated API response is available offline.
